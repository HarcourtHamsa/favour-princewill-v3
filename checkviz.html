Introducing Checkviz

Checkviz, a visitor management system, sought to create a user interface (UI) to enhance user experience and streamline the visitor check-in process. Companies previously relied on a paper sign-in sheet for visitors, leading to security concerns and time-consuming manual data entry for the receptionist.

Goal

The primary goal was to design a user-friendly and efficient UI that would:

  • Simplify the visitor registration process.
  • Improve clarity and ease of use for staffs and visitors.
  • Enhance the overall visual appeal of the Checkviz platform.
  • Reduce onboarding time for new users.
  • Improve Building Security.

Design Process

  • User Research:I conducted user research with staffs and frequent visitors to understand their pain points and preferences regarding visitor management systems.
  • User Flow Optimization: I analyzed and optimized the visitor check-in flow, eliminating unnecessary steps and streamlining the process.
  • Wireframing & Prototyping: I created low-fidelity wireframes to establish the website's layout and user flow, followed by high-fidelity prototypes for usability testing.
  • Visual Design: I designed a clean and intuitive UI that prioritized clarity and ease of use. Visual elements were incorporated to enhance user experience without compromising efficiency.

Design Solution

The Checkviz UI features:

  • A step-by-step visitor registration process with clear instructions.
  • Large, easy-to-read fonts and buttons for effortless navigation.
  • A minimalist design that prioritizes functionality and reduces visual clutter.
  • Intuitive icons and visual cues to guide users through the process.
  • Clean as seamless dashboard design.

The Checkviz UI resulted in a more user-friendly and efficient visitor management experience. Usability testing indicated a significant reduction in check-in time and improved satisfaction from both staffs and visitors. The new UI is expected to boost user adoption and overall system satisfaction.
